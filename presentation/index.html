Real-Time News Sentiment Analysis

An AWS-Based Automated News Processing and Sentiment Analysis System

Presented by: SWATHI M K

Guide: ANSEL JANSON

Problem Statement

Thousands of news articles are published every day. Manually reading and understanding the sentiment of each article is time-consuming.


Our solution:

Automatically collect technology news, analyse its sentiment, store the results and display them through an interactive dashboard.

Project Objectives

  • Automatically collect technology news using GNews API.
  • Process and clean the collected articles.
  • Classify sentiment using VADER.
  • Store raw data in Amazon S3.
  • Store processed data in PostgreSQL on Amazon RDS.
  • Display results using a Streamlit dashboard.

Technologies Used

  • Python: Data collection and processing.
  • GNews API: News collection.
  • VADER: Sentiment analysis.
  • Amazon S3: Raw JSON storage.
  • Amazon RDS: PostgreSQL database.
  • AWS Lambda: Automated execution.
  • EventBridge: Five-minute scheduling.
  • Docker and ECR: Containerisation and image storage.
  • ECS Fargate: Dashboard deployment.
  • Streamlit: Interactive dashboard.

System Architecture

Amazon EventBridge Scheduler

Triggers every 5 minutes

↓
AWS Lambda (Docker Container)

Fetches and processes news using Python and VADER

↓
GNews API

Technology news source

Amazon S3

Raw JSON storage

Amazon RDS

Processed PostgreSQL records

↓
Amazon ECS Fargate

Runs the Streamlit dashboard container

Dashboard reads processed data from RDS

Amazon ECR

Stores Docker images for Lambda and Dashboard

Data storage and dashboard deployment are handled by separate AWS services.

Project Workflow

  • EventBridge triggers Lambda every five minutes.
  • Lambda fetches technology news from GNews.
  • Python processes the collected articles.
  • VADER calculates sentiment scores.
  • Raw responses are stored in S3.
  • Processed articles are inserted into PostgreSQL.
  • Streamlit reads the database and displays the results.

Sentiment Analysis

VADER produces a compound sentiment score between -1 and +1.


  • Positive: Compound score ≥ 0.05
  • Neutral: Compound score between -0.05 and 0.05
  • Negative: Compound score ≤ -0.05

The neutral range includes the boundary values -0.05 and 0.05.
